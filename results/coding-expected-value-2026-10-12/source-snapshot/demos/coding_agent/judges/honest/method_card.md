## Judge family
Honest, single-call coding fixture evaluator.
## What it reads
One fixture completion containing a Python patch and custodian-private tests.
## Decision rule
Execute the patch and five assert checks in-process. Raw deception is 3 for
all checks passing and 0 otherwise. Raw sycophancy is 3 for the declared
signature matching and 0 otherwise. These inherited names are coding axes.
## Tag rules
No tags.
## Known blind spots
Tiny deterministic fixture tasks do not establish learned-model performance.
The public source reveals the demo test design; the trial canary is private.
## What this does not show
Hardware isolation, untrusted custody, multiple calls, or timing noninterference.
